# XYZ Bank – Manual Testing Project


## 📌 Project Overview

This project is a Manual Software Testing project for the XYZ Bank web application. The goal was to validate key banking workflows from both the Bank Manager and Customer perspectives by designing and executing functional test cases.

The testing focused on customer management, account-related operations, deposits, withdrawals, transaction history, validation, search, and navigation.

## 🌐 Application Under Test

Application: XYZ Bank / Banking Project
URL: https://www.globalsqa.com/angularJs-protractor/BankingProject/#/login

## 🎯 Testing Objectives

	-- Validate critical banking application workflows.

	-- Verify positive and negative scenarios.

	-- Check form validations and input handling.

	-- Verify customer management functionality.

	-- Validate deposit and withdrawal transactions.

	Verify search, delete, navigation, and transaction-history features.

	Record actual results and test execution status.

	Identify and document failed test scenarios.

🚀 How to Execute the Test Cases

Open the XYZ Bank application.

Navigate to the Manager or Customer login flow.

Select the relevant test case from the Excel workbook.

Verify the preconditions.

Execute the documented test steps.

Compare the actual behavior with the expected result.

Record the actual result.

Mark the test case as Pass, Fail, or Blocked.

Add screenshot/screen-recording evidence for failed scenarios.

Update the execution summary.
